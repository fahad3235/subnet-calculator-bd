# Subnet Calculator BD

An offline, bilingual (EN/বাংলা) IPv4 subnet calculator. Type an address like
`192.168.1.10/24` and get the full subnet breakdown, split a network into
smaller subnets, or classify any IPv4 address — all in the browser, with zero
network requests.

## Problem

Subnet math is a daily chore for network students, admins, and homelabbers, but
most online calculators phone home with your input, show ads, or skip the
teaching aids (binary view, /31 notes, RFC 1918 classification). This is a
personal, offline tool that does the math transparently and explains it in
English or Bangla.

## Features

1. **CIDR calculator** — network, broadcast, mask (dotted + binary), wildcard,
   total addresses, usable hosts, first/last host, plus a per-octet binary view
   with network bits vs host bits color-coded. Handles /31 (RFC 3021) and /32
   host routes correctly.
2. **Subnet splitter** — split a network by subnet count (rounds up to the next
   power of two) or by target prefix; shows network/first/last/broadcast per
   subnet. Capped at 256 displayed rows with a note when more exist.
3. **IP checks** — classify any address: Private (RFC 1918), Public, Loopback,
   Link-local, Multicast, Reserved, CGNAT (RFC 6598), or Unspecified, with the
   governing RFC, legacy class (A–E), default classful prefix, and binary view.
4. **Bilingual EN/বাংলা UI** — persisted toggle, optional Bengali digits,
   copy-results button, strict input validation with clear error messages,
   empty states, and a 390px-friendly mobile layout.
5. **100% offline** — single static page, no CDNs, no fonts fetched, no
   analytics. Nothing you type leaves the device.

## Stack

- Plain HTML / CSS / JavaScript (no frameworks, no build step)
- `js/subnet.js` — pure IPv4 math (browser + node compatible)
- `js/i18n.js` — generated by `gen_i18n.py` (pure ASCII, Bengali as `\uXXXX`)
- Tests: node unit tests + headless-Chrome CDP smoke tests

## Prerequisites

- A modern browser (for the app)
- Node.js 18+ and Python 3 (for tests / i18n regeneration)

## Install / run

No install. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
# or
python3 -m http.server 8080
```

## Dev commands

```bash
node tests/subnet.test.js        # 107 unit tests
node tests/smoke.mjs desktop     # 40 headless-Chrome checks
node tests/smoke.mjs mobile      # 41 checks at 390px
python3 gen_i18n.py              # regenerate js/i18n.js after editing strings
```

## Environment

No environment variables, no secrets, no backend.

## Testing

`tests/subnet.test.js` covers parsing (valid/invalid octets, prefixes, CIDR
forms), mask/binary conversions, subnet math for /0 /8 /24 /30 /31 /32, IP
classification across all special ranges, legacy classes, and splitter edge
cases (rounding, overflow, caps). `tests/smoke.mjs` drives the real UI in
headless Chrome (desktop 1280px + mobile 390px): computes, splits, checks,
language toggle with reload persistence, Bengali digits, error/empty states,
and asserts zero console/page errors.

## Deployment

Static site — works on GitHub Pages, Netlify, or any file host. Live demo:
https://fahad3235.github.io/subnet-calculator-bd/

## Limitations

- IPv4 only — no IPv6 support.
- Splitter displays at most 256 rows (full count is still reported).
- Copy button uses the Clipboard API where available.
- Educational tool, not a network planner: it does not validate whether a
  subnet plan is routable in your real network.
